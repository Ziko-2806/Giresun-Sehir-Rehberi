# Giresun Şehir Rehberi

Bu proje, Giresun iline ait temel şehir bilgilerini gösteren basit bir şehir rehberi uygulamasıdır. Kullanıcıların Giresun hakkında bilgi alabilmesini sağlar.

## 📌 Proje Özeti
“Giresun Şehir Rehberi”, bir şehir hakkında temel bilgiler sunan bir uygulamadır. Projede örneğin:
- Şehrin tarihi
- Gezilecek yerler
- Yeme-içme önerileri
- İletişim ve ulaşım bilgileri
gibi bilgiler yer alabilir.

Bu proje, kullanıcı dostu yapısı ile şehir hakkında hızlıca bilgi edinmek isteyenler için bir başlangıç amacını taşır.

## 🛠️ Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript
